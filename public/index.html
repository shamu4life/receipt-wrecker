Receipt Wrecker

GitHub

Your words as giant type, or a picture as glyph-art (from a link or a file). Paste the result into Twitch chat as a Cheer100 and it prints on the streamer's receipt printer.

Blocks: stacked top to bottom on the receipt
Add text and pictures; they print in order down the receipt. Reorder with ↑/↓, remove with ×. Too much for one receipt just tapes into more, and each is its own cheer (see the bits total under the preview).
Presets: save this whole stack and bring it back
Saved in this browser only. Export the JSON to move a setup to another device, or to survive a cache clear. An uploaded picture's link dies after 15 minutes, so a preset that used one loads with that block flagged for re-upload. A pasted link is left alone.
Starts each message with "Cheer<bits> " so it triggers the print. Turn it off to send a free test: a message with no cheer never reaches the printer, but it does go through chat's filters, so it shows whether the channel lets this text through before you spend bits on it.
Puts two rotating digits after the cheer ("Cheer100 07"). Twitch won't send the same message twice in a row within 30 seconds (it just isn't sent, and no bits are spent), and the digits make each copy different. They also print on the receipt, which is why this is off. Leave it off and wait 30 seconds before sending the same thing again.
How many bits each cheer spends (1 or more). Each taped part is its own cheer, so a multi-part message costs bits × parts. The total is shown under the preview.
How long one receipt prints before it is cut. Most 80 mm thermal printers stop at the Windows driver's paper length, often A4 (297 mm) — a tall stack is simply cut off there, not shrunk. Tall content is split across several receipts so none is lost (each is its own cheer, with printer-bot's header between them). If yours prints longer, or you set the driver to Roll Paper / continuous, raise this; the Print size ruler below shows where each number lands so you can read your real length off the tape.
Print size ruler is one cheer that prints the numbers 1 to 13, each one a size bigger than the last. If the numbers grow, Giant type works on this printer today, and you can see every size it offers on real paper. If they all come out the same size, printer-bot changed its style: use Hanzi tiling instead.

Paste into the official Twitch web/mobile chat and send as a ≥100-bit cheer. Only the first-party client actually cheers.

Held or blocked by chat? Bot filters (symbols, repetition, duplicates) move around as mods tune them. This tool already stacks the odds in your favor: letters-only art keeps the symbol ratio low, and run-capping avoids repetition walls. Short of a VIP or bot permit, which bypass all of it, there is no way to guarantee delivery. If a message is held, resend it, shorten it, or drop the column count and try again.
